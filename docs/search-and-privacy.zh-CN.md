# 搜索与隐私

[返回 README](../README.zh-CN.md) · [English](./search-and-privacy.md)

## 不记得名字，也能尝试找回文件

Nearkeep 先返回文件名与关键词匹配结果，需要时再由本地语义检索补充受支持文档中的相关片段。例如，描述“客户拖着不付款会有什么责任”，可以帮助定位已提取文字中的付款条款。结果仍需结合原文核对。

安装包内含 **Qwen3-Embedding-0.6B Q8_0**，通过本地 llama.cpp 运行时检索。它是检索模型，不生成聊天回复或摘要。

## 正文支持范围

| 内容 | 当前能力 |
| --- | --- |
| 带文字层的 PDF | 文字提取与检索 |
| TXT、Markdown、CSV、TSV、JSON、LOG | 文字提取与检索 |
| 扫描 PDF | 不提供完整 OCR |
| Office 文档与其他格式 | 暂不提供正文检索 |

长文、大文件与处理时限可能导致部分正文未被覆盖。模型冷启动可能需要数十秒；模型忙碌或不可用时，普通搜索仍可使用。搜索历史保存在本机，支持单条删除。

文件导入、预览和正文检索是不同能力：能收进资料库的文件，不一定支持正文检索。

## 本地处理的含义

当前文件管理、索引与模型检索在 Mac 上运行，不将文件正文发送给云端 AI。系统安全检查、邮件反馈和用户主动打开的外部内容可能联网。

尚未完成全部场景的断网与流量审计；本地处理不等于任何情况下都完全离线，也不代表绝对安全。

当前尚未提供线上账号、云同步、生成式问答或摘要。重要文件请另做独立备份，本地资料库不能替代备份服务。
