# Nearkeep 1.0.2

This update refines the Library sidebar and empty state, and keeps the quick-search hint in sync with your shortcut settings.

**[Download for Mac · Apple Silicon](https://github.com/jayueseven/Nearkeep/releases/download/v1.0.2/Nearkeep-1.0.2-macOS-arm64.zip)** · [简体中文](https://github.com/jayueseven/Nearkeep/blob/main/docs/releases/v1.0.2.zh-CN.md)

## Changes

- **Live shortcut hint:** the Library search bar immediately shows the latest successfully registered quick-search shortcut. Clearing it removes the hint; cancelled or failed changes keep the effective binding.
- **Sidebar toggle:** updated expanded-state icons, a subtle divider transition on hover, and a gentle fade to the existing logo when the sidebar is collapsed. Button size and keyboard behavior are retained.
- **Navigation feedback:** sidebar icons lift slightly on mouse hover, with a small detail animation on the Images icon. Text and hit areas stay still. Reduced Motion disables the animation.
- **Empty Library:** updated Nicole artwork with more space above the title, preserving the illustration's size and clarity in light and dark appearances.
- **Fresh setup:** no storage folder or shortcuts are assigned before you choose them. Explicitly saved shortcut bindings are retained. Set shortcuts in Settings when needed.

The editable shortcut controls, Settings wording and save-confirmation spacing from 1.0.1 are retained. Nicole visibility is a Library-window shortcut; Library visibility and quick search are global while Nearkeep is running. The existing PPTX embedded-cover fallback is also retained when native Quick Look cannot produce a thumbnail.

## Install or update

Download and extract the ZIP. Quit Nearkeep normally before replacing the app. Keep your Library storage folder and an independent backup. Do not run local development and distribution copies together; they share a data identity.
