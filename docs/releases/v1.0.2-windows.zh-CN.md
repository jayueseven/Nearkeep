# Nearkeep 1.0.2 · Windows x64

这一版让 Windows 的侧栏动效、空状态和快捷键提示与 macOS 1.0.2 保持一致。

**[下载 Windows 版 · x64](https://github.com/jayueseven/Nearkeep/releases/download/v1.0.2-windows/Nearkeep-1.0.2-Windows-x64-Setup.exe)** · [English](https://github.com/jayueseven/Nearkeep/releases/tag/v1.0.2-windows)

## 更新内容

- **快捷键提示：**保存快速搜索快捷键后，界面提示立即更新；清空快捷键后，不再显示旧提示。
- **侧栏：**更新侧栏交互动效。收起时，顶部图标和悬停时的 Nearkeep 标志都与下方导航图标居中对齐。
- **资料库空状态：**更新普通空资料库和空文件夹的插图。

## 使用说明

- **全新安装：**资料库为空，不预设存储目录或快捷键。可在设置中录制或清空 Nicole、资料库窗口和快速搜索的快捷键。
- **HEIC/HEIF 文件：**此版本不含应用内预览。原文件保留，可用兼容应用打开。
- **本地语义检索：**需要 [Microsoft Visual C++ 运行库（x64）](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist)，没有此运行库仍可使用普通搜索。

## 安装与更新

1. 下载 EXE 安装包。安装包未签名，Windows 可能显示安全提示。
2. 如需更新，请先正常退出 Nearkeep，并为资料库保留独立备份。更新设计上会保留已有的资料库和设置。
3. 运行 EXE 完成安装。首次打开时选择存储文件夹。如需使用快捷键，可在设置中配置。
