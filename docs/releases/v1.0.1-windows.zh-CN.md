# Nearkeep 1.0.1 · Windows x64

这是 Nearkeep 首个公开的 Windows x64 版本。用资料库收集、整理和查找本地文件，也可以通过桌面伙伴 Nicole 快速收纳。

**[下载 Windows 版 · x64](https://github.com/jayueseven/Nearkeep/releases/download/v1.0.1-windows/Nearkeep-1.0.1-Windows-x64-Setup.exe)** · [SHA-256](#sha-256) · [English](https://github.com/jayueseven/Nearkeep/releases/tag/v1.0.1-windows)

## 更新内容

- **全新安装：**资料库为空，不预设存储目录或快捷键。可在设置中录制或清空 Nicole、资料库窗口和快速搜索的快捷键。
- **HEIC/HEIF 文件：**此版本不含应用内预览。原文件保留，可用兼容应用打开。
- **本地语义检索：**需要 [Microsoft Visual C++ 运行库（x64）](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist)，没有此运行库仍可使用普通搜索。

## 安装与更新

1. 下载 EXE，在下载目录打开 PowerShell 并运行 `Get-FileHash -Algorithm SHA256 -LiteralPath '.\Nearkeep-1.0.1-Windows-x64-Setup.exe'`，确认与下方 SHA-256 一致。安装包未签名，Windows 可能显示安全提示。
2. 如需更新，请先正常退出 Nearkeep，并为资料库保留独立备份。更新设计上会保留已有的资料库和设置。
3. 首次打开时选择存储文件夹。如需使用快捷键，可在设置中配置。
