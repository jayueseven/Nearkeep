# Nearkeep 1.0.1

This maintenance update improves editable shortcuts and refines Settings and the save confirmation.

**[Download for Mac · Apple Silicon](https://github.com/jayueseven/Nearkeep/releases/download/v1.0.1/Nearkeep-1.0.1-macOS-arm64.zip)** · [SHA-256](https://github.com/jayueseven/Nearkeep/releases/download/v1.0.1/SHA256SUMS.txt) · [简体中文](https://github.com/jayueseven/Nearkeep/blob/main/docs/releases/v1.0.1.zh-CN.md)

## Changes

- **Editable shortcuts:** record or clear shortcuts for Nicole visibility, Library visibility and quick search. Supported custom combinations are saved; conflicts and registration failures are reported. Escape or losing focus cancels recording without replacing the previous shortcut.
- **Correct scope:** Nicole visibility responds only while the Library window is active and Settings and other dialogs are closed. Library visibility and quick search remain global while Nearkeep is running. Recording suspends the existing shortcut actions.
- **Settings polish:** retain the compact shortcut capsules, add an inline recording prompt and circular clear/cancel control, correct its hit area, and distinguish unset shortcuts. Light and dark appearances are supported.
- **Save confirmation:** more space above the Cancel and Copy/Move buttons.
- **About:** show the actual application version and name; remove the model description from the version row.

## Install or update

Download the ZIP and `SHA256SUMS.txt` to the same folder and run `shasum -a 256 -c SHA256SUMS.txt`. Quit Nearkeep normally before replacing the app. Keep your Library storage folder and an independent backup. Do not run local development and distribution copies together; they share a data identity.
