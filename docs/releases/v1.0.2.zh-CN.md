# Nearkeep 1.0.2 更新记录

本次更新优化资料库侧栏和空状态，并让搜索栏的快捷键提示随设置即时同步。

**[下载 Mac 版 · Apple Silicon](https://github.com/jayueseven/Nearkeep/releases/download/v1.0.2/Nearkeep-1.0.2-macOS-arm64.zip)** · [English](./v1.0.2.md)

## 更新内容

- **快捷键提示实时同步：**资料库搜索栏立即显示最新成功注册的快速搜索快捷键。清空后移除提示；取消、冲突或注册失败不会显示未生效的键位。
- **侧栏开关：**更新展开状态图标，悬停时分隔线轻缓移动；收起时平滑切换到原品牌 Logo。保持按钮热区和键盘行为。
- **菜单图标反馈：**鼠标悬停时侧栏图标轻抬，图片图标增加细微动作。文字和热区不移动；开启“减少动态效果”时不播放动画。
- **空资料库：**更新 Nicole 配图，加大配图与标题的留白，保持原显示尺寸，适配浅色和深色模式。
- **首次使用：**不预设保存目录或快捷键，按需在设置中选择。已明确保存的快捷键继续保留。

保留 1.0.1 的快捷键编辑控件、设置文案及保存确认间距。Nicole 显隐快捷键仅在资料库窗口前台、设置和弹层关闭时生效；窗口显隐与快速搜索在 Nearkeep 运行时全局生效。原生 Quick Look 无法生成 PPTX 缩略图时，既有的内嵌封面后备能力也继续保留。

## 安装与更新

下载并解压 ZIP。正常退出 Nearkeep 后替换应用，保留资料库保存文件夹与独立备份。不要同时运行 local 和发行版，两者共享资料身份。

本页为 macOS 版本说明。[Windows x64 版](./v1.0.1-windows.zh-CN.md)保持不变，本批界面更新尚未同步到 Windows。既有[搜索与隐私限制](../search-and-privacy.zh-CN.md)及 [文件同步边界](./v1.0.0.zh-CN.md)仍适用。当前仍需手动下载更新。
