# Nearkeep 1.0.1 更新记录

本次小版本修复快捷键编辑，优化设置与保存确认的细节。

**[下载 Mac 版 · Apple Silicon](https://github.com/jayueseven/Nearkeep/releases/download/v1.0.1/Nearkeep-1.0.1-macOS-arm64.zip)** · [English](./v1.0.1.md)

## 更新内容

- **快捷键可编辑、可清空：**显示/隐藏 Nicole、显示/隐藏窗口、快速搜索支持录制受支持的自定义组合。冲突或注册失败会明确反馈；按 Esc 或失焦取消时保留原值。
- **保持正确作用范围：**Nicole 快捷键仅在资料库窗口前台、设置及其他弹层关闭时生效；窗口与快速搜索仍为全局快捷键，需要 Nearkeep 运行。录制期间不触发旧快捷键。
- **设置样式优化：**保留原有紧凑胶囊，录制时在胶囊内显示提示和圆形清空/取消按钮；修正圆形热区，未设置状态以弱化颜色区分，适配浅色和深色模式。
- **保存确认留白：**加大“取消”和“复制/移动”按钮上方的间距。
- **关于页文案：**显示实际应用版本与名称，移除版本行中的模型说明。

## 安装与更新

下载并解压 ZIP。正常退出 Nearkeep 后替换应用，保留资料库保存文件夹与独立备份。不要同时运行 local 和发行版，两者共享资料身份。
